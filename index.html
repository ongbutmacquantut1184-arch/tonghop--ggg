2. Nguồn Kết Nối Dữ Liệu

Hạ tầng tích hợp CDP → API → Messaging của Golden Gate

📦 Salesforce CDP

Quản lý dữ liệu loyalty, phân đoạn khách hàng sâu (High/Medium/Low), trigger hành trình phức tạp dựa trên lịch sử giao dịch 365 ngày.

Dữ liệu: Profile, Transaction, Loyalty Tier, Redemption History

🧠 Antsomi CDP

Behavior tracking realtime, tự động hóa chiến dịch dựa trên sự kiện (booking, app activity, web visit), hỗ trợ decisioning nhanh.

Dữ liệu: Event Stream, Behavioral Signals, Campaign Triggers

🔌 GapOne API — Middleware Điều Phối

Lớp trung gian nhận payload từ cả 2 CDP, map thông tin OA ID + Template ID + biến cá nhân hóa, điều hướng gửi ZBS qua Zalo hoặc fallback SMS.

7. Đề Xuất Mô Hình Tiêu Chuẩn Cho F&B

Khung kiến trúc tùy biến dựa trên mục tiêu kinh doanh (Reference Model)

🎯 Chọn Mục Tiêu Chuyển Đổi (Có thể chọn nhiều)

Kiến Trúc Triển Khai Tiêu Chuẩn

1. Thu Thập Data (Input)
  • Phần mềm POS / Quản lý nhà hàng

    Tận dụng hệ thống sẵn có, không cần thay mới. Phải có tính năng lưu SĐT khách hàng.

  • Hệ thống Booking / Đặt bàn

    Các web form hoặc POS module quản lý bàn.

  • Zalo Mini App (Khuyên dùng)

    Thay thế App riêng tốn kém. Tích hợp trực tiếp thẻ thành viên, Menu, Booking trên Zalo.

2. Xử Lý Logic (Decisioning)
  • Middleware API / Gateway

    Hệ thống trung gian kết nối POS và Zalo. Tự động kích hoạt tin nhắn dựa trên sự kiện (Event-driven).

  • CDP Lite / CRM Cơ Bản

    Phân tập khách hàng tự động (Segment Mới/Cũ/VIP). Quản lý rule sinh mã Coupon cá nhân hóa.

3. Tương Tác (Output)
  • Zalo OA & ZBS (Kênh Chủ Lực)

    Chi phí rẻ, tỷ lệ mở cao. Đăng ký Tick Vàng để tăng độ tin cậy.

  • Kịch bản: Tin nhắn Giao dịch

    Báo xác nhận đặt bàn, Gửi mã OTP, Báo bill thanh toán.

  • Kịch bản: Chăm sóc & Tiếp thị

    Gửi ưu đãi sinh nhật, Tặng voucher quay lại, Khảo sát dịch vụ CSKH.

8. Lộ Trình Triển Khai Thực Tế (Roadmap)

Chiến lược lấy ngắn nuôi dài, đo lường ROI qua từng giai đoạn

Giai Đoạn 1

Quick Wins (Tối Ưu Chi Phí)

Tháng 1 • Triển khai: Ngắn hạn

KPI: Giảm 30% - 50% chi phí gửi SMS
  • Setup Zalo OA chuẩn hóa, xin Tick vàng
  • Tích hợp API gửi mã OTP qua Zalo (Thay thế SMS đắt đỏ)
  • Tự động xác nhận Booking / Đặt bàn
  • Chạy thử và đo lường tỷ lệ Delivery Rate
Giai Đoạn 2

Retention (Thu Thập & Phản Hồi)

Tháng 2 - 3 • Triển khai: Trung hạn

KPI: Thu thập 20% Feedback / Tăng Data 15%
  • Gửi template Rating/Survey tự động sau khi KH dùng bữa
  • Tích lũy Data KH vào hệ thống CRM/CDP Lite
  • Mapping SĐT với Zalo UID để phục vụ remarketing
Giai Đoạn 3

Loyalty & Scale (Tự Động Hóa)

Tháng 4 - 6 • Triển khai: Dài hạn

KPI: Tăng 10% Tỷ lệ khách quay lại (Repeat Rate)
  • Triển khai Loyalty System / Ví Coupon
  • Automation gửi chúc mừng Sinh Nhật (kèm Voucher)
  • Cá nhân hóa ưu đãi theo phân khúc khách hàng (RFM)
  • Đo lường ROI tổng thể Dashboard (CTR, Conversion)

⚠️ Rủi ro cần lưu ý khi bắt đầu

  • Mất kết nối API: Cần có phương án fallback sang SMS khi mạng chập chờn hoặc Zalo gửi lỗi để tránh rớt OTP/Booking.
  • Chất lượng Dữ liệu: POS nhân viên gõ sai SĐT khách hàng sẽ làm tỷ lệ gửi thành công sụt giảm nghiêm trọng.
  • Quy định Zalo: Khuôn khổ nội dung ZBS (Transaction vs Promotion) rất khắt khe, cần duyệt chuẩn template từ sớm.
